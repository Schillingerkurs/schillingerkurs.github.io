## Privacy Policy

This site uses no analytics or tracking scripts, and sets no first-party cookies of its own. There is no comment system, so no third-party comment provider (e.g. Disqus) is loaded either.

The only personal-data-adjacent element on this site is a `mailto:` contact link, which simply opens your own email client — no data is transmitted to this site by clicking it.

This site is hosted on GitHub Pages. As the hosting provider, GitHub processes some data (such as server request logs) to serve the site; see [GitHub's general privacy statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement) for details on what GitHub Pages itself collects.
